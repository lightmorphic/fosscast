Privacy

This page is about fosscast.org, the website. The software is a separate matter and is covered at the bottom.

This website

It is a single page of HTML and one stylesheet, served from a server in Europe. There is no analytics, no tracking pixel, no advertising network, no third-party script and no external font. Nothing you do here is recorded beyond the ordinary web server log, which holds the request and its address for a short time so the machine can be kept running and abuse can be spotted.

Nothing is asked of you, so nothing is held about you. There is no account, no form, no newsletter and no comment box.

If you email us

The address on this site reaches a person. Your message and address are kept for as long as the conversation is useful and then deleted. It is not added to any list.

The software

FOSSCast runs on your server, not ours. We never see it, cannot reach it, and receive nothing from it: it checks for no updates, reports no usage and calls nobody. What it collects about your listeners is therefore between you and them, and the honest summary is that it collects very little: aggregate download counters with no listener profile and no cookie for the audience.

If you are running FOSSCast for other people, the privacy notice those people need is yours to write, because you are the one holding their data.

Your rights

There is almost nothing here to exercise them on, but if you think we hold something about you, ask and we will tell you, correct it or delete it. If you are not satisfied, the Information Commissioner's Office takes complaints at ico.org.uk.

Self-hosting

Up in about five minutes

You need a Linux machine with Docker, a domain pointed at it, and ports 80 and 443 reachable. That is the whole shopping list.

git clone https://github.com/lightmorphic/fosscast.git
cd fosscast
cp .env.example .env   # fill it in, every value is explained
docker compose up -d --build

HTTPS certificates arrive by themselves. Already running nginx or a tunnel? There is a stack without the bundled proxy, and the README covers Cloudflare Tunnel and Tailscale too.

One instance runs one podcast, on purpose: it keeps the whole thing small enough to understand and to trust.

# Contributing

Short version: **bug reports yes, code contributions no.**

## Code contributions are not accepted

FOSSCast is developed by one person and released under the GPL. Pull
requests are not accepted and will be closed unread. This is not a
judgement on anyone's code - it is a licensing constraint, explained
below, and it is not going to change.

Please do not spend your time on a pull request for this project. If
you want to change FOSSCast for your own use, fork it. The GPL gives
you that right and you do not need our permission.

## Why

FOSSCast is free software and always will be. It is also the basis of a
paid hosted service, which is how the work on it gets funded.

Code you write belongs to you. If we merged it, we would hold it only
under the GPL, and we could not use it in the hosted service. Every
merged contribution would split the project into parts we can build on
and parts we cannot. Refusing contributions outright keeps the free
edition whole and keeps the paid service honest about what it is built
from.

## What we do want

- **Bug reports.** If something is broken, tell us. A clear description
  of what you did and what happened is worth more than a patch.
- **Security reports.** See `SECURITY.md`. Please report privately.
- **Ideas.** Tell us what is missing. We may well build it.

## If you send code anyway

Sometimes people paste a fix into a bug report, or send a patch by
email. We would rather that did not happen, but if you do send us code,
by sending it you agree to the following:

> You confirm the code is yours to give, that you wrote it, and that no
> employer or other party has a claim on it. You give Lightmorphic an
> unrestricted, permanent, worldwide, royalty-free right to use, modify
> and distribute that code, in any part of FOSSCast, under any licence,
> including in proprietary and commercial versions. You keep your own
> copyright and may use your code however you like elsewhere. You are
> not entitled to payment for it.

If you are not willing to grant that, do not send code - send a bug
report describing the problem instead, and it will be just as useful.

*This is a plain-language statement of intent, not legal advice. If a
contribution ever matters enough to argue about, get a solicitor to
look at it.*
